## Getting Started

1. Run `npm install`
2. Run `npm run dev`

The development server stores generated files in `.next-dev`, separate from
production build output in `.next`. Use the local URL printed by Next.js in the
terminal; if port 3000 is already occupied, Next.js may select another port.

## Authentication API

Set `NEXT_PUBLIC_API_BASE_URL` in the website root `.env.local` file to the backend
origin (or its `/api/v1` URL). This is a public API URL, not a secret. The auth
proxy uses it for regular-user sign-in, email verification, password reset, and
HTTP-only session cookies.
